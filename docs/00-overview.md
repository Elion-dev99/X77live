# 00. システム概要

## 目的

**X77live** は [x77.jp](https://x77.jp) の2ショットライバー一覧から **大阪店ボーイのみ** のオンライン状態（待機中 / 通話中 / オフライン）を自動取得し、Discord チャンネル `#x77live` 等へ通知する Bot です。

幹部向けの用途:

- リアルタイムで「誰がオンラインか」を把握
- EX（シフトカレンダー）と照合し「出勤なのに未オンライン」「シフト外オンライン」を検出
- 営業日ごとのオンライン稼働時間を集計・レポート

## システム構成

```
┌─────────────┐     GET      ┌──────────┐
│  x77.jp     │◄─────────────│          │
│  dgdgdg.com │◄─────────────│ X77live  │──────► Discord (#x77live)
│  EX API     │◄─────────────│   Bot    │──────► 管理者 DM
└─────────────┘              └──────────┘
                                   │
                                   ▼
                            data/config.json
                            data/reports/
                            data/backups/
```

## 通信方針

| チャネル | 用途 |
|----------|------|
| **LINE（人間）** | 幹部同士の連絡 |
| **LINE（Bot・日次のみ）** | 01:00 確定稼働サマリーのみ Messaging API でグループ送信（途中通知は送らない） |
| **Discord `#x77live`** | Bot の通常通知・ログ |

## 用語

| 用語 | 意味 |
|------|------|
| **boy_id** | dgdgdg / x77 上のボーイ識別子（文字列） |
| **ロスター** | 大阪店在籍ボーイ一覧（`dgdgdg.com/boy/list.php?shop_id=4`） |
| **営業日（sessionKey）** | `YYYY-MM-DD` 形式。営業 **13:00 〜 翌 01:00 JST** を1日とする |
| **営業時間** | デフォルト 13:00〜01:00 JST。監視・通知・シフト照合の基準 |
| **EX** | 開発者所有のシフト API（Cloudflare Workers） |
| **定期通知** | 10分間隔の Discord Embed（オンライン状況 + シフト不一致） |

## ステータス定義

| 表示 | 内部定数 | x77 HTML 判定 |
|------|----------|---------------|
| 🟢 待機中 | `STATUS.WAITING` (`待機中`) | `live_situation02` |
| 📞 通話中 | `STATUS.IN_CALL` (`通話中`) | `live_situation01` |
| ⚪ オフライン | `STATUS.OFFLINE` (`オフライン`) | 一覧にいるが上記なし |

## デフォルト運用パラメータ

| 項目 | デフォルト |
|------|-----------|
| 監視間隔 | 2 分 |
| 定期通知間隔 | 10 分 |
| 営業時間 | 13:00 〜 翌 01:00 JST |
| 日次サマリー送信 | 毎日 01:00 JST（終了した営業日） |
| 週次サマリー | 日曜営業終了後（月曜 01:00 付近） |
| シフト猶予 | 出勤開始 + 15 分後から未オンライン判定 |
| 対象店舗 | 大阪店 `shop_id=4` |

## リポジトリ

- **GitHub**: `Elion-dev99/X77live`
- **エントリ**: ルート `index.js` → `src/index.js`
- **Node.js**: >= 18（ESM）
- **主要依存**: discord.js ^14

## 制約・注意

1. **同一 Discord トークンで Bot を2つ同時起動しない**（二重通知の原因）
2. x77.jp は年齢確認 Cookie が必要（Bot が自動取得）
3. HTML 構造変更時は `src/scraper.js` の更新が必要
4. `config.json` は Bot-Hosting の `data/` に永続化（Git には含めない）
